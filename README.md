## How to view

- **On GitHub Pages:** open the site link. A page code after `#` opens that page directly, for example `#M-01` for Marriage or `#E-01` for the equation finder.
- **Offline:** download `index.html` and open it in any browser.

## How to publish (GitHub Pages)

1. Upload `index.html` and this `README.md` to the repository through the GitHub website.
2. Go to Settings, then Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
3. Wait a minute or two. The site link appears on the same Pages screen.

## How to update

Upload a new `index.html` over the old one. The site refreshes on its own in a minute or two.
